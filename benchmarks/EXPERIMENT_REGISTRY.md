# Experiment registry

All experiments are **planned, not executed**. [Machine-readable contracts](experiments.json) define hypothesis, checkpoint, dataset status/configuration, resources, criterion, baseline, protocol, stopping rule, interpretation and next decision. The dataset version names are proposed identifiers and are not existing HF releases.

- **PB00:** Pinned Wan baseline and one-expert trainer can reproduce cache/export/inference at selected geometry within bounded hardware Status: `planned_gpu_not_executed`.
- **PB01:** Accurate camera/event captions on owned balanced single-shots improve held out camera adherence without photorealism/temporal regressions Status: `planned_gpu_not_executed`.
- **PB02:** Noise expert and caption detail each cause measurable target gain Status: `planned_gpu_not_executed`.
- **PB03:** LongCat improves quality or continuation/cost under eligible license Status: `planned_gpu_not_executed`.
- **HA00:** Owned task verifiers/harness adaptation are correct and Holo 35 serving fits qualified hardware Status: `planned_environment_and_gpu_not_executed`.
- **HA01:** Acknowledgement, timeouts, structured memory and recovery improve verified success with frozen weights Status: `planned_environment_and_gpu_not_executed`.
- **HA02:** Cleared DragOn train improves unseen-screenshot drag grounding Status: `planned_recipe_qualification_required`.
- **HA03:** Fresh verified successful/recovery trajectories improve unseen app success Status: `planned_recipe_qualification_required`.
