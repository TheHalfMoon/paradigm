# The 2B Hala proposal: feasibility and falsification

**Scope:** each proposal claim is a hypothesis. Public cards and source/config metadata were inspected on 13 October 2026. No model weights, GPU, GUI benchmark or billing system was run. Exact checkpoint: [`Qwen/Qwen2-VL-2B-Instruct` at `895c3a49bc3fa70a340399125c650a463535e71c`](https://huggingface.co/Qwen/Qwen2-VL-2B-Instruct/tree/895c3a49bc3fa70a340399125c650a463535e71c), Apache 2.0. Its BF16 safetensors total **4,418,050,768 bytes** in the repository tree. The [config](https://huggingface.co/Qwen/Qwen2-VL-2B-Instruct/raw/895c3a49bc3fa70a340399125c650a463535e71c/config.json) includes a 32-layer vision encoder and 28-layer text model. A 2B label is not the full runtime memory or time budget.

| Claimed property | Finding | Required test |
|---|---|---|
| 0.2 s click | **Unverified; misleading as end-to-end latency.** No matching hardware, image, tokens, queue or screen/tool timing was supplied. | Timestamp capture, crop/encode, network, vision prefill, decode, policy, action, UI settle and verification separately; report cold/warm p50/p95/p99 by hardware and screen size. |
| $0.00002/action | **Unverified.** Implies $0.02/1,000 model actions before retries, Pro, idle, network, support and human review. | Meter GPU/CPU seconds and dollars per *verified completed task*, include queue/idle amortization and retries. |
| 500 labeled screenshots | **Plausible grounding pilot, insufficient evidence for broad agent capability.** Independent apps/layouts/tasks and label reliability matter more than frame count. | Hold out app/template/source groups and language before any augmentation; measure grounding hit rate and task success separately. |
| 10,500 via resizing/translation | **Arithmetic augmentation, not 10,500 independent samples.** Resizes share labels and can break coordinates; translated text may change line wraps, direction and target location. | Re-render actual localized UI, transform boxes/points exactly, audit RTL and OCR, keep every derivative in its parent's split. |
| 10,000 OSWorld samples | **Rejected as stated.** The public [OSWorld-Verified trajectories card](https://huggingface.co/datasets/xlangai/ubuntu_osworld_verified_trajs/raw/main/README.md) describes *evaluation trajectories* and explicitly marks training “not recommended.” Count, rights for embedded screens, and a clean task-disjoint corpus were not established. | Never train on benchmark tasks or their traces. Use newly generated tasks, synthetic apps, and separately licensed training datasets with task/provenance denylist. |
| Brain LoRA + Eye LoRA | **Unproven benefit.** Two adapters share one base; switching and incompatible state/prompt format can hurt. | Frozen base, single multitask LoRA and two-LoRA at equal labeled examples/steps/parameter budget; measure switch overhead and task success. |
| Free Kaggle T4 in six hours | **No demonstrated recipe or entitlement.** A 16 GB T4 can run some 2B QLoRA configurations, but vision tokens, optimizer, checkpointing, sequence length, image resolution and service quotas determine feasibility. T4 lacks native BF16; use supported FP16/quantized path only after one optimizer/save smoke test. | Record Kaggle current quota/terms, exact GPU, cold setup, peak VRAM, steps/hour, loss, gradients and a saved/reloaded adapter. Stop at quota, OOM or invalid gradients. |
| ~1.2 GB GGUF | **Numerically plausible for 4-bit *core weights* (~1.0–1.2 GB), not verified for a working multimodal package.** Vision encoder/projector, tokenizer, runtime and KV cache add size. No exact conversion/parity was performed. | Pin converter/runtime, quantify every artifact, compare BF16 versus quantized action/grounding success on held-out screenshots, measure RAM and CPU/GPU latency. |
| $5/month Aladdin + Desktop Commander | **Business and integration hypotheses.** Aladdin's adopted architecture uses founder-hosted AI, while its local authority layer has typed, approval-bound tools. | Model active/idle/effect cost and support by usage cohort; integrate only through the untrusted proposal contract, with local authority unchanged. |

The first 500 labels should contain element boxes/points, target text, action preconditions, expected postconditions, and negative/no-action examples. Label ambiguity and inter-annotator agreement on a double-labeled subset are recorded; screenshots alone do not teach recovery or plans. Add short success and failure/recovery trajectories from synthetic browser and desktop tasks. Split by application, layout template and task family *before* image or language augmentation, then seal the test. Browser screenshots and Windows UIA differ; include both. DragOn may supply grounding material only after per-asset and benchmark-overlap screening as described in [dataset forensics](DATASET_FORENSICS.md). Rights to redistribute a dataset wrapper do not automatically clear website text, logos or personal data in screenshots.

If speed is the goal, compare an untuned [ShowUI-2B](https://huggingface.co/showlab/ShowUI-2B/tree/cabec4fcc48d15ffd3efe0b33ea9bc7d41509d60) and [Qwen3-VL-2B](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct/tree/89644892e4d85e24eaac8bacfd4f463576704203) before collecting a large Qwen2-VL dataset. For browser tasks, [Fara1.5-4B](https://huggingface.co/microsoft/Fara1.5-4B/tree/776a33ae5b2ad503796a97ae20fdc66f61d2feea) is an especially strong pre-trained alternative; its card reports substantial browser completion but states training data is English-only and other languages are out of scope. General Arabic UI performance requires direct tests for all candidates. Qwen3.5-4B is the broader provisional Flash pilot because its native vision and vendor visual-agent evidence span desktop; this remains a hypothesis.

**Go/no-go:** spend no training compute until frozen base and harness-only controls run. A 100–200 image annotation pilot is useful only if held-out grounding improves and task success responds. Reject the 2B training route if a released small model already beats it at the same task cost, if adapter gains vanish on unseen apps/Arabic, or if complete-task latency/cost misses the product target. The [first experiment](../../plans/HALA_FLASH_FIRST_EXPERIMENT.md) specifies the paired protocol.
