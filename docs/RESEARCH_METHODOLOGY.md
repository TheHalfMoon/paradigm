# Research methodology

Work proceeded through public primary sources, fresh multi-pass searches, model/dataset HTTP metadata, pinned source clones, actual RE A static analysis and genuine local metadata/tool validation. Search explored current releases and challengers as well as initial Wan/Holo hypotheses, using official cards/licenses/reports and counter evidence. Search output is lead generation, not proof. Repo initially empty and public; live owner/rules/open items were inspected and main boots trapped without inventing prior work.

Evidence labels: **VERIFIED** for a narrowly stated fact actually observed/recomputed; **STRONGLY SUPPORTED** for consistent primary evidence with a nun executed implication; **PRELIMINARY** for engineering judgment/proposed recipe; **UNVERIFIED** for missing execution/source detail; **CONTRADICTED** for claims refuted by inspected facts or incompatible metric interpretation. Separately tag origin:source fact, publisher measurement, recomputed publisher metadata, our tool run, proposal or independent GPU experiment. VERIFIED model card content is not VERIFIED model performance.

Sources [registry](../research/evidence/source-registry.json) retain URL, accessdate, HTTP outcome, bytes, SHA and immutable model/source revisions where available. Failed raw paths, gates and PDF conversion failures were investigated through lawful alternatives; no agreement accepted. Source hash identifies bytes, not claim truth. Ex a response hash differs from publisher HTML hash. Reports link official sources and preserve unknowns. Original full cards/papers/copyrighted payloads are not republished into repo.

Compatibility tiers: source inspected → parser flag recognized → environment resolved/import checked → weights loaded → gradient/cache/export checked → GPU memory/throughput measured → quality gain replicated. This assignment reaches first two tiers for Plume, config/source inspection for Hala; it does not claim latter tiers. RE A static facts are corroborated against source and boundary limitations recorded. Python training repositories were analyzed directly, rather than falsely treated as RE A'sJSengineoutputs.

Dataset rights reviews separate code/weights/metadata/asset/music/likeness/privacy/output licenses. FetchedsmallevalJSONrecordsverifyschema, not train quality or gold success. Publisher index aggregations are not independent benchmark executions. Budgets separate provider quotes from duration/memory assumptions. Weighted model recommendations use hard license/capability gates and ordinal judgment with switching experiments, not pseudo quantitative quality scores.

Validation uses std lib source/manifest/schema/link/registry checks, actualJevofflinepresetvalidation, Ali baba OCR delegation rule bundle with host review, Graft static integration graph, RE A analysis andgitexactheadverification. NoLLMreviewAPIorcommercialreviewservicewasactivated. A host review is not an independent second researcher. Remaining real GPU/environment tests are explicit future gates; no fake GPU/E2 Epass is manufactured.
