# Provenance, privacy and contamination policy

An asset cannot enter training until rights status=approved_under_conditions, all conditions actually met, a named human reviewer signs an audi table decision, and license/source evidence is retained privately. A configuration string isnot rights proof. GitHub stores schemas/research and red acted metadata only; private HF holds approved payloads and restricted evidence with scoped tokens.

Required lineage: original sourced URL/asset ID, creator/rights holder, acquisition time, exact license/version or contract ID, evidence SHA, original file SHA, transformations/time codes, parent asset/group ID, source app/identity/story/template, caption generator revision/prompt/input SHA, human review, split/dataset commit, decoder/VAE/T5 cache config SHA and experiment/checkpoint IDs. Evidence contradictions default quarantine. Preserve withdrawal/expiration conditions and attribution in manifests and model release package as applicable.

Hash dedup occurs before clipping; pHash/embedding near-duplicate clusters unite reencodes, crops and adjacent segments. Split clusters/source productions/identities/templates **before augmentation**. Stable group-split decisions live in manifest and must not change because an experiment needs more data. Benchmark IDs/text/trajectories, gold verifiers and benchmark-related generated task instructions are deny listed from training. Inherited checkpoint contamination remains unknown; label it rather than promise zero leakage.

No persistent training videos, datasets or weights on the personal computer. Public source cards/configs/papers and small forensic JSON metadata samples read for this research are not training payloads. Remote processing workers fetch only approved selected files, write ephemeral cache, validate upload SHA/HF commit, retain provenance/tombstones, and delete only verified worker scratch paths after persisted copies checked. Never log tokens/secrets or screen private content into GitHub.

Disaster recovery: reproducible source manifest plus authorized encrypted remote owned backup where permissions allow; resumable HF uploads and commit SHA checks. HF is primary, not an assumption that free private storage is unlimited or a single host cannot fail. Rights restricted assets may prohibit backup redistribution; record approved locations before copying. Takedown process locates assets→descendants→caches→datasets→checkpoints and opens human release/retirement decision without claiming deleting data automatically unlearns the model.
