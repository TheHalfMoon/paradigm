# Paradigm

Paradigm is the permanent research and development headquarters for Plume, an open-weight cinematic video generation derivative, and Hala, an open-weight computer-use agent derivative.

Status: research bootstrap on 2026-10-12. No training, performance improvement, or benchmark leadership has been demonstrated. The repository was empty at inspection; there is no previous research history to reconstruct.

The research branch will establish dated evidence, model and dataset license checks, reproducible evaluation protocols, architecture decisions, and implementation-ready experiments. Research both programs; execute Plume first.

Original Paradigm material is Apache-2.0. External code, model weights, datasets and assets retain their own licenses and conditions.
